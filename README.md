# 📧 MailFlow - Gmail Clone

MailFlow is a modern Gmail-inspired email application built using **HTML, CSS, JavaScript, Firebase Authentication, and Cloud Firestore**. It allows users to send, receive, manage, and organize emails with a clean and responsive interface.

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/mailflow.git
```

Open the project

```bash
cd mailflow
```

Install Firebase configuration

```javascript
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};
```

Run using Live Server or deploy to Firebase Hosting.
